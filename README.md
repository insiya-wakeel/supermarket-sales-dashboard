# Supermarket-sales-dashboard

📌 **Overview**

   This interactive Power BI dashboard designed to analyze supermarket sales and revenue performance across USA, Mexico and Canada.The report offers users actionable insights into total transactions, profits, returns          profit margins, and regional performance, empowering data-driven decision making for retail businesses.

🎯 **Objectives**

* Track monthly sales and revenue performance
* Highlight monthly sales and revenue trends within the selected year
* Provide a focused city-level analysis for Portland using interactive navigation

📊 **Dashboard Pages**

1. Sales & Revenue Overview
    View aggregated sales KPIs, regional breakdowns, and trends over time. Includes:
     * Total transactions, profit, and returns vs. targets.
     * Profit margins and return rates by product brand
     * Revenue trends by month and region
     * Map-based visualizations for geographical insights

2. Portland Sales Page
   * Dedicated report page for Portland
   * Accessed using a button with bookmark action
   * Provides city-level breakdown of sales and revenue
   * Enables stakeholders to quickly isolate Portland’s contribution     

🔑 **Key Features**

   * Monthly sales and revenue analysis (within the selected year)
   * Bookmark navigation with buttons for seamless page transitions
   * City-specific insights (Portland) for detailed analysis
   * Clean and interactive design focused on storytelling

🛠️ **Tools Used**

   * Power BI Desktop – Dashboard design & interactivity
   * DAX – Custom measures for sales & revenue analysis
   * Power Query – Data transformation & cleaning

💡 **Purpose**

   This project demonstrates
      * Proficiency in building interactive dashboards
      * Storytelling using bookmarks and navigation buttons
      * Ability to uncover business insights from supermarket data
